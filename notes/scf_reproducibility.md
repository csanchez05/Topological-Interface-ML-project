# CoGe bulk SCF calculations: brief reproducibility guide

> Layout note (2026-10-02): run paths below are as they were during the campaign. The selected runs now sit directly in each `scf/`, `dos/` and `bandstructure/` folder; the other runs and the campaign scripts and records are under `archive/` at the same relative path. See [calculations/CoGe_Bulk/README.md](../calculations/CoGe_Bulk/README.md).

Campaign records are in `archive/results/b20_campaign/CoGe_sym_native/smearing_rerun_20260828/`.

The smearing rerun was submitted on 28 August 2026 as Slurm array 6942 on QCG/IRIS. The steps below describe the calculations performed; completion and validation are reported separately.

1. **Structures and electronic-structure method.** Use the archived `sym00000`–`sym00622` POSCARs: 623 eight-atom B20 CoGe cells (4 Co + 4 Ge), with cubic lattice parameter 4.6294498444 Å. The manifest identifies 311 regular and 312 inverted structures, equivalent within their respective chiral families; they are transformed representations, not 623 distinct material phases. Use VASP 6.4.3, PBE exchange–correlation, and PAW datasets `Co 02Aug2007` and `Ge 05Jan2001` in Co/Ge order, giving 52 valence electrons per cell. These dataset labels and PBE were confirmed from OUTCAR metadata.

2. **Common numerical settings.** Perform fixed-geometry SCFs with `ENCUT=600 eV`, `PREC=Accurate`, `EDIFF=1E-8 eV`, `ALGO=Normal`, `NSW=0`, `IBRION=-1`, and `ISYM=2`. Use a Γ-centered 11×11×11 k-point mesh with zero shift. The tight SCF tolerance helps compare symmetry-equivalent structures, and the Γ-centered mesh supports tetrahedron integration; the cutoff and mesh were retained from the preceding campaign, without a new convergence sweep.

3. **Non-SOC calculation and classification.** Use `vasp_std`, `ISPIN=2`, initial `MAGMOM=4*1.0 4*0.0`, and `NELM=100`. Start the `ISMEAR=-5` SCF from that structure's archived, converged non-SOC `ISMEAR=1`, `SIGMA=0.1 eV` CHGCAR, with `ISTART=0`, `ICHARG=1`. The preceding campaign's non-SOC seed calculations started from atomic charge superposition (`ISTART=0`, `ICHARG=2`). After successful convergence, read the spin-independent value from the last `fundamental gap:` line in OUTCAR (`BANDGAP=KPOINT`), and count non-integer EIGENVAL occupations across all k points, bands and available spin channels, with tolerance 1e-6. **Keep -5 only if gap >0.01 eV AND the fractional-occupation count is zero; run -1 if gap <=0.01 eV OR that count is nonzero.** Failed/incomplete probes or unreadable classification data stop the worker; they are not automatically called metallic. The 0.01 eV cutoff is this campaign's conservative operational threshold, not a universal metal/insulator boundary. `BANDGAP=KPOINT` controls reporting, not the occupations themselves. [VASP BANDGAP documentation](https://vasp.at/wiki/BANDGAP).

   For exact implementation: the original shell classifier measured distance to the nearest of 0, 1 or 2; the recovery parser used 0 or 1. In either case, a distance >1e-6 was counted as fractional. This distinction did not change any rerun decision here: all 1,246 recorded probes had negative gaps and therefore already failed the gap criterion.

4. **Metallic rerun and new density.** For a metallic probe, copy its newly converged CHGCAR into a separate run directory and perform a fresh self-consistent calculation with `ISMEAR=-1`, `SIGMA=0.05 eV`, `ISTART=0`, and `ICHARG=1`. Set `LCHARG=.TRUE.` and `LWAVE=.FALSE.` throughout; the final SCF updates the input density and writes a new CHGCAR. Fermi–Dirac occupations smooth the metallic Fermi surface; 0.05 eV was chosen as a narrower width than the original 0.1 eV, without a width-convergence study. `SIGMA=0.05` also appears in the -5 input but supplies no broadening for that method. The -5→-1 choice was this project's protocol, not a universal requirement: VASP also recommends -5 for accurate bulk total energies. [ISMEAR](https://vasp.at/wiki/ISMEAR), [smearing guidance](https://vasp.at/wiki/Smearing_technique), [ICHARG](https://vasp.at/wiki/ICHARG).

   The script launched this conditional second calculation within the structure's Slurm array worker, not as a new Slurm submission for each metallic result. All 623 non-SOC and 623 SOC probes selected -1. Their decisions are retained in [summary.tsv](../archive/results/b20_campaign/CoGe_sym_native/smearing_rerun_20260828/summary.tsv): `probe_gap_eV`, `fractional_occupations`, `classification`, and `final_ismear`.

5. **SOC calculation.** Seed `vasp_ncl` from the selected new non-SOC CHGCAR. Use `LSORBIT=.TRUE.`, `SAXIS=0 0 1`, `MAGMOM=24*0.0`, `LMAXMIX=4`, and `NELM=120`, retaining the common settings. Repeat the -5 classification and conditional -1 SCF independently for SOC, because SOC can change the electronic band edges. Each SOC -1 run is seeded from its own SOC -5 CHGCAR. The observed band counts are 34 non-SOC and 62 SOC; irreducible k-point counts are 76 and 121, respectively.

6. **Execution and retained results.** Each structure runs its stages sequentially in one Slurm array element: 6 MPI ranks, one thread per rank, 12 GiB RAM, one-day walltime, and at most 31 concurrent structures in `general`, excluding `qcg-docker`. Load `vasp/vasp.6.4.3-intel2024`; launch with `srun --mpi=pmi2 --ntasks=6 --ntasks-per-node=6 --cpus-per-task=1 --cpu-bind=cores`. Use `KPAR=3`, `NCORE=1`, single-threaded BLAS/OpenMP, and Intel MPI core pinning respecting the Slurm cpuset. This retained the established six-rank execution settings. Preserve the -5 and -1 outputs under each stage's `smearing_rerun_20260828/ismear_m5` and `ismear_m1`; `final` points to the selected result. Worker records retain input and CHGCAR seed hashes. There were no ionic relaxations, band-path calculations, or DOS stages in this rerun.

For exact potential identity, the original combined Co/Ge POTCAR SHA-256 is `08b3e4431b75444a8d528b517107c06d93c57fd32145a7418628437fd11353dd`. Reuse the licensed original alongside the archived POSCARs, INCARs and KPOINTS. The recorded `final_energy_eV` is VASP's finite-smearing free energy `TOTEN`; use one consistent energy definition in subsequent comparisons.
